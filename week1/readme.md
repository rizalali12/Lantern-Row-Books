# Lantern Row Books
 
A responsive landing page for a fictional independent bookstore. Built with plain HTML and CSS, with no frameworks and no JavaScript.


## Overview
 
Lantern Row Books is a one-page website that introduces a neighbourhood bookshop. Visitors can browse new fiction, nonfiction and staff favourites, and see upcoming readings and book clubs.


## Content notice
 
All book titles, authors, prices, staff notes and event details are sample content for design purposes only. The cover images and the bookshelf illustration are original illustrations and do not depict real books.
